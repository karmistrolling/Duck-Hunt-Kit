# 🦆 DuckHunt STEM Kit

Welcome to the DuckHunt STEM Kit repository!

This project combines Arduino, Unity, SolidWorks, 3D printing, and electronics to recreate the classic Duck Hunt experience using a physical light gun. The project was designed as an educational STEM kit to teach students practical engineering skills through hands-on design, manufacturing, programming, and assembly.

Link to download the unity game files needed: https://drive.google.com/file/d/1vLEDoXD_YanyN-FuPw409PTkXCnzGYte/view

---

# Project Overview

The DuckHunt STEM Kit allows users to:

- Design a custom light gun in SolidWorks
- 3D print the completed model
- Assemble the electronics
- Upload Arduino code
- Connect the hardware to a Unity game
- Customize the game and physical model
- Learn professional engineering and manufacturing techniques

Whether you're a beginner or an experienced maker, this repository contains everything needed to build the complete project.

# What You'll Learn

Throughout this project you'll gain experience with:

- Arduino programming
- Unity game integration
- SolidWorks CAD
- 3D printing
- Mechanical design
- Electronics assembly
- Soldering
- Desoldering
- Wire crimping
- Heat shrink tubing
- Heat-set brass inserts
- Troubleshooting hardware and software
